# Проверки без 1С

После установки пакета: `python -B -m unittest discover -s tests -v`.
Набор содержит прежние 31 тест линтера, 45 тестов протокола, 19 тестов диалога
и проверки новой безопасной сборки/извлечения. Тесты используют синтетические
CFB и переносимые очищенные протоколы; база и прикладной корпус не нужны.

Полная проверка установки и поставки одной командой (setuptools из
`requirements-build.txt` и pip должны быть установлены):

```powershell
python scripts/verify_package77.py
```

Скрипт копирует только исходники поставки в новый каталог `.artifacts/package77`,
строит sdist, из него wheel, создаёт чистое venv без системных пакетов,
устанавливает wheel без сети и запускает тесты из другого каталога без
PYTHONPATH. Проверяет консольную команду, `python -m`, наличие словаря,
единственную установленную дистрибуцию и P1/P2. Логи и summary.json сохраняются
также при отказе. Каталог каждого запуска новый; скрипт не удаляет деревья.
`--output` выбирает отсутствующий каталог, `--build-python` и `--runtime-python`
позволяют отдельно выбрать интерпретаторы сборки и проверки.

Отрицательные проверки включают повреждённую/неоднозначную ERT, NUL,
неверную кодировку, символ вне CP1251, существующий выход и hardlink на вход,
гонку создания результата, изменение входа, порчу временного файла,
ошибки синхронизации/публикации/очистки и изменение постороннего потока/каталога.
Сборка проверяется при переходах между обычным и mini-потоком.

Три проверки symlink могут быть пропущены, если Windows не разрешает их создание;
это явно отражается в итогах. В sandbox Windows вызов `resolve(strict=True)`
может получать отказ доступа даже при доступном чтении. Такой запуск не считается
успехом: для приёмки требуется среда с доступной проверкой файловой идентичности.
При ограниченном TEMP задайте TEMP/TMP в доступный каталог до запуска Python.

Исследовательские тесты этапа 2 запускаются отдельно:
`python -B -m unittest discover -s research/platform77/tests -v`.
Они не доказывают работоспособность нового платформенного runner: он ещё не создан.
Локальный корпус проверяется отдельно по хешам, без изменения оригиналов;
не включайте базу и прикладные ERT в переносимый набор.
