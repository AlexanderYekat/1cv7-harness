# Задача 070. Очередь suite через MCP на общем copy_path

Задача принята владельцем 10 ноября 2026 года.

MCP включает ожидание замка `copy_path` для дочерних сценариев
`suite`. Сценарий использует свой лимит открытия. Если отмена
приходит до захвата замка, текущий сценарий получает `blocked`
с причиной `cancelled`, а оставшиеся — `skipped`. Набор публикует
итоговые JSON и JUnit.

Проба использует один MCP-сервер и реальную 1С 7.7.027. Первый
`run` удерживает временную копию с живыми CDB, 1С и OLE-клиентом.
Его launcher задерживает выдачу разрешения на `Initialize`. Два
запроса `suite` с двумя сценариями каждый используют тот же
`copy_path`. Проба отменяет один набор до освобождения пути,
сверяет состояние копии и даёт первому `run` штатно завершиться.

В первой пробе скрипт проверял отсутствующее поле отчёта владельца и
закрыл MCP до завершения второго набора. Во время повтора чтение
промежуточного `suite.json` совпало с его заменой и привело к
`WinError 5`. Публикация `suite.json` и `junit.xml` теперь
повторяется до одной секунды при временном отказе доступа Windows.
Регрессионный тест проверяет оба файла.

## Итоговый нативный прогон

- Отмена через `notifications/cancelled` завершила первый набор с кодом 2
  после 3,623 с ожидания. Замок не захвачен, копия и нативный сеанс
  сценария не создавались. В итоговом JUnit один `error` с причиной
  `cancelled` и один `skipped`. MCP не отправил ответ на отменённый
  запрос. Снимки 856 файлов, хеш `1Cv7.MD`, замок, метка и
  COM-регистрации владельца совпали, его процессы оставались живы.
- Владелец штатно завершился с результатом 42. Первый сценарий второго
  набора захватил путь после 87,038 с ожидания. Оба сценария прошли
  последовательно на свежих копиях с отдельными `run_id`, одним
  `Initialize` и результатом 42 каждый. MCP вернул код 0. В JUnit два
  успешных testcase, ссылки и SHA-256 совпали с дочерними `run.json`.

Копия и замки удалены. Опись исходной базы, список баз, COM-регистрации
и список процессов 1С совпали со снимками до прогона. Прошёл 71
автоматический тест suite, MCP и защиты копии.

Сводка — `.artifacts/s70-accepted/verified.json`. Локальная проба
запускается командой `python -B .local/s70-verify.py <новый-суффикс>`.
