# Этап 3: пакет, CLI и воспроизводимая сборка ERT

Дата: 13 октября 2026 года. Предшествующий этап: приёмка platform77.

Работа состоит из двух последовательных изменений.

1. Перенести существующие `lint77`, `compiler_protocol77`, `ert_module`, словарь,
   их тесты и переносимые fixtures в `src/harness77` и `tests`. Сначала подтвердить
   прежнее поведение. Корневой Git становится источником кода продукта;
   оба вложенных репозитория и их истории сохраняются без изменений.
   Добавить wheel/sdist, ресурс словаря и команду `harness77`.
2. Поверх прежнего CFB-кода добавить отдельные операции `extract` и `build`.
   Сборка принимает явные текст, шаблон и новый выходной путь. По умолчанию
   строго кодирует CP1251, нормализует переводы строк в CRLF, сверяет текст,
   остальные потоки и записи каталога, перечитывает временный файл с диска,
   публикует только проверенный артефакт. Отчёт содержит хеши и кодировку.

CLI сохраняет схемы и диагностики прежних lint/compiler-protocol. Новые операции
возвращают JSON версии 1; успех сборки не означает компиляцию. Работают пути
с пробелами и кириллицей, CWD не должен совпадать с репозиторием. Выходы сборки
и извлечения не перезаписывают существующие файлы, включая ссылки на входы.

77MCP, сервер, runtime, формы и прикладные проекты не включаются в пакет.
Прямое чтение модулей MD существующим CFB-кодом сохраняется; структурированные
метаданные 77MCP исключены из подтверждённой готовности.

Приёмка: прежние тесты проходят; wheel установлен в чистое окружение и проверен
из другого каталога без devtools/77MCP/PYTHONPATH; словарь в поставке; sdist
собирается в wheel; переносимые P1/P2 дают прежние 60/7 диагностик. Новые проверки
подтверждают сохранность входов и посторонних потоков, повторяемость сборки,
отклонение неверной кодировки, повреждённого контейнера и конфликтного выхода,
ошибок записи/проверки/публикации. Локальный корпус сравнивается отдельно.

Контракт долгих расчётов фиксируется в `docs/contracts.md`; реализация и нативная
приёмка остаются обязательной частью этапа 4. Исследовательские сроки 30/145 с
не становятся ограничением общего CLI.
