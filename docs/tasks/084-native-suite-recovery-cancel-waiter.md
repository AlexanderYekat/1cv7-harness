# Задача 084. Отмена запроса за владельцем восстановленной копии

Задача принята владельцем 11 ноября 2026 года.

Проба воспроизводит аварию [задачи 083](083-native-suite-concurrent-recovery.md).
Первый повтор ждёт штатного выхода прежней 1С, заменяет копию на том же
`copy_path` и снимает обе старые COM-регистрации. Проба удерживает его
после `Initialize` и `check`, пока второй повтор ждёт путь.

Проба отменяет второй запрос через `notifications/cancelled` и дожидается
выхода его CLI. Отчёт должен зафиксировать `cancelled` до захвата замка
и запуска 1С. Снимок копии, замка и COM-регистраций владельца должен
сохраниться. После снятия паузы владелец завершает проверку. Затем новый
MCP-запрос использует тот же путь. Оба успешных запроса должны вернуть
`42` после одного `Initialize` каждый.

## Прогон на 1С 7.7.027

Команда из корня репозитория для существующего локального стенда

```powershell
python -B research/mcp/verify_suite_recovery77.py --stand .local/stage21-native/stand.toml --project .local/stage21-native/s3/cases/m-same/project.toml --output .artifacts/s84-native --retries 2 --cancel-waiter
```

## Результат

- Владелец захватил путь после 11,109 с ожидания, создал свежую копию
  и снял обе оставленные COM-регистрации.
- Второй запрос дважды сообщил об ожидании пути. Отмена завершила его
  CLI с кодом 2 после 10,618 с ожидания. В `run.json` записаны
  `blocked`, `cancelled` и `acquired=false`. Запуска 1С и вызова
  `Initialize` не было. MCP принял `ping` после отмены и не отправил
  ответ на отменённый `run`.
- На момент выхода отменённого CLI копия, замок, обе регистрации
  и процессы владельца совпали со снимком перед ожиданием. Владелец
  продолжил работу и вернул `42` после одного `Initialize`.
- Новый запрос получил тот же путь сразу после штатной очистки
  владельца, создал свежую копию и вернул `42` после одного
  `Initialize`.

Первый результат прерванного набора, `suite.json` и JUnit сохранились.
Временная копия, замок и защита замка удалены. Исходная база, список
баз, COM-регистрации и процессы 1С совпали со снимками до прогона.
Локальный протокол — `.artifacts/s84-native/verified.json`.
