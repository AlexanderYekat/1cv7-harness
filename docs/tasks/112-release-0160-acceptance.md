# Выпуск 0.16.0 и проверка скачанного wheel

0.16.0 опубликована 19 ноября 2026 года. В неё вошли TOML-рецепты задач
110–111 и штатная команда `fixture-render` из 112.
[Релиз](https://github.com/AlexanderYekat/1cv7-harness/releases/tag/v0.16.0).

Аннотированный тег указывает на `854b535bd6fd73f34bfecdaf906900a157323b97`.
До публикации CI этого коммита прошёл на Windows (Python 3.11, 3.13 и 3.15)
и Linux (Python 3.13). После выпуска временная ветка проверки удалена.
[CI](https://github.com/AlexanderYekat/1cv7-harness/actions/runs/44488676850).

Wheel собран из sdist, подготовленного из `git archive`. После нормализации
переводов строк содержимое пакета совпало с принятой сборкой 112. Манифест
проверен по фактическим SHA-256 33 нативных файлов. Из установленного wheel
выполнено 645 пакетных тестов, включая 5 пропусков.
[Отчёт сборки](../../.artifacts/s112-release/package/summary.json),
[сверка содержимого](../../.artifacts/s112-release/build-identity.json).

Из GitHub скачаны wheel, sdist и `SHA256SUMS.txt`. Байты всех трёх совпали
со сборкой, размеры и хэши — с опубликованными метаданными. SHA-256 wheel
`bcb8b15a74d1fc6ca7dd5d44fa9c1bd7796c676daa931a10dd882f8be8b9d6c6`.
[Сверка скачивания](../../.artifacts/s112-release/publication-verified.json).

Скачанный wheel установлен без сети в отдельное окружение
`C:/MyProjects/h77-0160-download`. Все 76 файлов пакета сверены побайтно.
Нативные циклы на Windows / 1С 7.70.027 / DBF дали `passed → failed → passed`
для каждого документа. Встроенный рецепт услуг дал единственное расхождение
`/service_type` (`1 → 2`), явный рецепт счёта-фактуры — `/comment_ok` (`1 → 0`).
Во всех шести запусках UI прошёл. После возврата модулей прежние ожидания
снова прошли. Файлы `.1s` совпали с принятой 112 побайтно, JSON-входы —
с учётом переводов строк. Во всех фазах одного цикла входы были побайтно
одинаковы. База, реестр и чужие процессы сохранились, копия и lock удалены.
[Нативная проверка](../../.artifacts/s112-release/native-verification.json),
[независимая сверка](../../.artifacts/s112-release/native-independent.json).
