# Приёмка задачи 013: сверка видов по именам вместо «ERT под свою базу»

Дата: 19 октября 2026 года. Статус: **принято.** Задание — [013-kind-name-checks.md](013-kind-name-checks.md).
Исходный HEAD: `e51dbd1`.

## Что реализовано

- **Продукт** (`src/harness77/form77.py`, `metadata77.py`, `artifacts.py`, `run77.py`).
  1С переводит номер поля вида в имя по копии метаданных внутри ERT и ищет вид
  по имени в открытой базе, поэтому:
  - номер каждого поля вида собранной ERT должен быть в её копии, иначе отказ
    сборки;
  - целевая база (`build --metadata`, `[build] metadata`, база стенда в `run`)
    сверяется по именам: вида нет — отказ со списком всех таких видов и элементов,
    другой номер того же вида — не отказ;
  - копия шаблона остаётся (`kept`), если содержит все новые виды, и новые поля
    получают её номера; иначе копия заменяется метаданными базы (`replaced`), а номер
    каждого прежнего поля вида переводится по имени (меняется только поле 17,
    перевод — в `changes`);
  - имя вида существующего поля сравнивается с именем его номера по копии шаблона.
  Отчёт сборки получил `form.kinds` (элемент, имя, номер в ERT и в целевой базе).
- **`run`:** `metadata_mismatch` заменён сверкой по именам: если `1Cv7.MD` базы
  стенда не тот, что у сборки, `platform_check` до запуска 1С проверяет в нём виды
  формы — отсутствующий вид даёт `blocked` (`metadata_missing_kinds`), итог —
  `metadata_check` этапа.
- **`form-extract`:** виды всегда называются по копии ERT; `--metadata` их больше
  не переименовывает, а сверяет по именам (`kinds`, `missing_in_metadata`). Схема
  описания — по-прежнему версия 3.
- **Нативная проба** (`research/forms`): модуль без обращения к данным
  `kinds_module77.1s`, профили `prepare_kinds77.py`, приёмка `verify_kinds77.py`;
  `verify_corpus77.py` считает отсутствующие виды и виды с другим номером.
  Контракт — [contracts.md](../contracts.md#описание-формы-задачи-008-011-012-и-013).

справочником — `Вид()` пуст, а поле держит элемент «Сотрудники» (K5b). Правило 1
остаётся отказом: без перевода поле теряет вид; исход записан до изменения
