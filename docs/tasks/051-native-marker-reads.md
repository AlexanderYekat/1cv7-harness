# Задача 051. Чтение маркеров нативного запуска

Задача принята владельцем 9 ноября 2026 года в указанном охвате.
Основание приёмки — поручение «принимай, коммить».

В задаче 049 запуск прервался при чтении `initialize-permit`, а другой
монитор заблокировал отчёт при чтении `ert-result-finished`. Проверка 051
воспроизводит оба отказа и сверяет число вызовов 1С после восстановления.

## Воспроизведение

На исходном коде `2b0d621` проба удерживала каждый уже видимый файл
эксклюзивным дескриптором Windows. Реальный 32-битный VBScript получил
ошибку 70 непосредственно от `FSO.OpenTextFile`. Старый код продолжил
работу с закрытым `TextStream` и сообщил ошибку 54 «Недопустимый режим
файла». Проба Python прочитала видимый `ert-result-finished` и получила
`PermissionError` с `errno=13`. Сводка и исходный VBScript находятся в
`.artifacts/s51-baseline-locks3`. Проба воспроизводит механизм отказа.
Какой процесс удерживал файл в исходных запусках 049, не установлено.

## Изменение

- VBScript сохраняет ошибку сразу после открытия `initialize-permit`.
  Только ошибка 70 допускает повтор открытия. Чтение и закрытие
  проверяются отдельно. Перед выходом из шлюза сверяется ID запуска.
- Python повторяет чтение уже опубликованных `ert-*-started` и
  `ert-*-finished` при ошибке доступа. Перед каждой попыткой монитор
  проверяет отмену и общий срок сеанса. Чужой ID и ошибочная кодировка
  по-прежнему отклоняются.
- На повтор доступа отведено около одной секунды и максимум 26 попыток с паузой
  около 40 мс. Диагностика содержит файл, операцию, исходный код ошибки,
  номер попытки и время. Повтор не публикует новый маркер и не вызывает 1С.

## Проверка

```powershell
python -X utf8 -B research/platform77/probe_marker_reads77.py --output .artifacts/marker-reads-new
```

Контрольные пробы в `.artifacts/s51-controlled-reads` подтвердили
восстановление после снятия блокировки разрешения, отказ при постоянной
блокировке обоих файлов, чужой ID разрешения и отмену до Initialize.

В нативном запуске `70f949e3-9b59-4df3-a687-e43a9adffb08` на свежей
копии проверочный launcher `.local/s51-native-launcher.py` удерживал
оба файла до первого неуспешного
чтения. В журнале есть ошибка 70 до Initialize и ошибка 13 при чтении
готового `ert-result-finished`. После снятия блокировок прошли оба чтения.
Счётчики перед реальными вызовами и ответы 1С подтвердили один
Initialize, по одному `check`, `open`, `result` и `verify` и 63
уникальных вызова шагов. Отдельно подтверждены один Delete, одна запись
и повторное открытие той же фактуры с итогом 110. Источник, список баз и
чужие сеансы сохранены. Копия удалена, её блокировка освобождена.
Сводка `.artifacts/stage51-native-verified.json` прошла с `issues=[]`.

Прошли 147 тестов платформы и 210 тестов форм. Обычный launcher выполнил
все три сценария 049 в одном наборе `840645e7-41cd-4a78-91a1-4c2509336753`.
Сводная сверка `.artifacts/stage51-regression049-verified.json`
подтвердила запись, отмену и ожидаемый отказ с `issues=[]`.
