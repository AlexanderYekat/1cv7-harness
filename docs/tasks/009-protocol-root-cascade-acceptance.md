# Приёмка задачи 009: корень и каскад в протоколе компилятора

Дата: 18 октября 2026 года. Статус: **принято, ждёт коммита.** Задание —
[009-protocol-root-cascade.md](009-protocol-root-cascade.md). Исходный HEAD: `882a3fe`.

## Что реализовано

- **Каталог сообщений.** `harness77 catalog` добавляет раздел `messages`:
  72 сообщения компиляции и 23 ошибки исполнения из `1crcrus.dll` (номер, текст,
  блок). Блоки — по опорным строкам, другая раскладка — отказ. Пакетный
  `catalog77.json` сгенерирован заново: прежние разделы не изменились, генерация
  из установленной платформы даёт тот же файл (тест).
- **Разметка** (`src/harness77/triage77.py`). Каждая диагностика получает
  `message_id`, `argument`, `role` (`root`|`cascade`|`link`|`unknown`), `cause`,
  `confidence`, `rule` и `explanation`; сводка — число по ролям, `complete`,
  `compiled_through_line`, `to_fix`. Ничего не удаляется и не переставляется.
  Модуль используется, только если строки протокола совпадают с ним. Правила
  и их основания — в [задании](009-protocol-root-cascade.md#исходы-проб-и-окончательные-правила-до-приёмки).
- **`harness77 triage`** — протокол Конфигуратора или нативный протокол загрузки,
  необязательный модуль (`--source` или `--ert`), выход — новый файл или stdout.
  Контракт — [contracts.md](../contracts.md#корень-и-каскад--команда-triage-задача-009).
- **`run`**: при диагностиках загрузки этап `platform_check` размечает их по модулю
  ERT своего запуска (поле `triage`). Launcher этапа 4 передаёт `column`
  и `source_line`. `compiler-protocol` и его контракт v1 не менялись.

## Границы

- Правила установлены на 7.70.027 и модулях внешней обработки. Модули MD,
  другие версии платформы, сообщения 1С++ и FormEx (`unknown`) не проверялись.
- Каскад заголовка проверен для имени встроенной функции в параметре (`Строка`).
  Ключевые слова в параметрах дают другие сообщения; там уверенность ниже.
- Без модуля правило «съеденного присваивания» не применяется: в P1 строки
  306–309 остаются корнями с уверенностью `medium` и пояснением, что нужен модуль.
  В `run` модуль есть всегда.
- Ошибки исполнения каталог опознаёт, но не размечает.
- Разметка — подсказка: после исправления корней нужна новая компиляция.
  Строки после остановки компиляции 1С не проверяла.
