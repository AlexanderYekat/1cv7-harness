# Этап 5, задача 018: имена объектов метаданных в коде модуля

Дата: 21 октября 2026 года. Предшествующая задача — [017](017-poll-round.md).
Приёмка — [018-metadata-names-acceptance.md](018-metadata-names-acceptance.md).

## Зачем

Модуль 7.7 обращается к объектам конфигурации по именам: `Перечисление.Булево.Да`,
`Константа.АдресОрганизации`, `ВидыСубконто.Договоры`, `СоздатьОбъект("Справочник.Банки")`,
`ОткрытьФорму("Отчет.АнализСчета")`, `ТЗ.НоваяКолонка("Товар", "Справочник.Номенклатура")`.
Опечатка в таком имени или имя из другой конфигурации обнаруживается только при
исполнении этой строки, то есть часто — у пользователя. `harness77 lint` этого не видит:
L7711 знает глобальные атрибуты `Константа` и `Перечисление`, но не их состав.

Имена объектов уже читаются из `1Cv7.MD` (`metadata77`, задачи 012–013: справочники,
документы, перечисления, планы счетов). Задача расширяет чтение на остальные разделы
и сверяет с ними имена в коде. Уровень правил — по исходу настоящей 1С 7.7, как в 005.

## Охват

1. **Имена из `1Cv7.MD`.** `metadata77` читает по именам: константы (`Consts`),
   справочники (`SbCnts`), документы (`Documents`), перечисления и их значения
   (`EnumList` → `EnumVal`), регистры (`Registers`), отчёты (`ReportList`), обработки
   (`CalcVars`), журналы документов (`Journalisters`), планы счетов и виды субконто
   (`Buh` → `Plans`, `SbKind`). Запись — `{"<номер>", "<имя>", …}`; запись другого вида —
   явный отказ, как в 012. Новые разделы читаются только для анализа: сборка формы
   (012–013) их не касается.
2. **L7712 — объект через глобальный атрибут не найден в метаданных базы.**
   `Константа.<Имя>`, `ВидыСубконто.<Имя>`, `ПланыСчетов.<Имя>`, `Перечисление.<Вид>`
   и `Перечисление.<Вид>.<Значение>`. Имя, за которым идёт `(`, — метод атрибута
   (`Константа.ПолучитьАтрибут(…)`, `Перечисление.Булево.КоличествоЗначений()`),
   не проверяется. Обращение через точку (`Объект.Константа.Х`) — не глобальный атрибут.
3. **L7713 — строка «Тип.Вид» в аргументе функции не найдена в метаданных базы.**
   Аргумент-строка целиком вида `"<Тип>.<Вид>"`, `"<Тип>.<Вид>.<…>"` или `"<Тип>.<Вид>#<…>"`
   у `СоздатьОбъект`, `ОткрытьФорму`, `ОткрытьФормуМодально`, `ОткрытьПодбор`,
   `ПолучитьПустоеЗначение`, `ВвестиЗначение`, `ПравоДоступа`, `НазначитьТип`,
   `НоваяКолонка`, `ВставитьКолонку`, `УстановитьПараметрыКолонки`,
   `УстановитьРеквизитСправочника` (из синтакс-помощника 7.70.027: эти параметры
   принимают имя типа или описатель объекта). Тип → раздел: `Справочник`, `Элемент` —
   справочники; `Документ`; `Журнал` — журналы, виды документов и `Подчиненные`
   (по синтакс-помощнику); `Перечисление`; `Счет`, `ПланСчетов` — планы счетов;
   `Регистр`; `Отчет`; `Обработка`. Вызов без точки, у которого в модуле или глобальном
   контексте есть одноимённая своя процедура, не проверяется.
4. **Контекст.** Без метаданных правила молчат (как L7711 без диалога).
   `lint --metadata 1Cv7.MD` задаёт базу текстовым модулям и ERT; модули самого
   `1Cv7.MD` сверяются с его собственными метаданными. `run` берёт `[build] metadata`
   проекта, иначе `1Cv7.MD` базы стенда; источник и хеш — в стадии `static`. MCP `lint` —
   аргумент `metadata`. Отчёт `lint` — поле `metadata` и `metadata_context_modules`.
   Имена сравниваются без учёта регистра.
5. **Нативное подтверждение** — пробы ниже; пакетная сверка: 1С сама перечисляет имена
   (`Метаданные.<Класс>(н).Идентификатор`) и обращается к каждому прочитанному имени.
6. **Корпус.** Модули `1Cv7.MD` базы стенда со своими метаданными, 424 ERT `ExtForms`
   с метаданными стенда и с метаданными «Торговля+Склад 9.2» базы владельца (только
   чтение), корпус КУДиР. Каждое срабатывание на модулях конфигурации разобрано.

**Не входит:** реквизиты объектов (`Спр.Реквизит`), имена форм после вида
(`"Справочник.Х.ФормаСписка"`), тексты запросов, `Метаданные.<Класс>("Имя")` (это и есть
проверка наличия), строки вне перечисленных аргументов (`Тип = "Справочник.Х"`),
английские имена атрибутов и типов, журналы расчётов, виды и группы расчётов, календари
(в доступных базах этих разделов нет — формат записей не проверен).

## Уровень правил

**error** — 7.7 отвергает модуль при компиляции; тогда защита
`Если Метаданные.Справочник("Х").Выбран() = 1` не помогает. **warning** — ошибка при
исполнении строки: обработка может быть рассчитана на несколько конфигураций и проверять
наличие вида (в корпусе `Метаданные.Справочник(…).Выбран()` — 360 раз); `--strict` делает
предупреждение ошибкой. Если 7.7 конструкцию с отсутствующим именем принимает без ошибки,
правило для неё не вводится или сообщает, что 1С сделает (тип без вида).

## Приёмка

Переносимо: чтение каждого раздела из синтетического `1Cv7.MD`; у L7712 и L7713
отрицательный, положительный и пограничный тест (метод атрибута, регистр, `#`, `Журнал.<вид
документа>`, своя одноимённая процедура, без метаданных — молчание); `--metadata` CLI, MCP
и `run`; все прежние тесты проходят. Нативно: таблица заполнена исходами 1С 7.7, линтер
совпадает с каждым исходом, пакетные пробы без расхождений, свои сеансы завершены.
На корпусе: модули `1Cv7.MD` стенда без срабатываний или каждое объяснено; итоги по
`ExtForms` для двух баз. Успех линтера по-прежнему не означает успешной компиляции.
