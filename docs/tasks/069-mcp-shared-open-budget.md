# Задача 069. Общий лимит open для ожиданий копии и стенда

Задача принята владельцем 10 ноября 2026 года.

Четыре запроса `run` отправлены одному MCP-серверу через stdio на стенде
1С 7.7.027. Проба удерживала штатные замок `copy_path` и мьютекс
COM-регистрации. Каждый замок отпускался через 120 с после первого
сообщения MCP о соответствующем ожидании. В коротком совместном прогоне
мьютекс оставался занят до ответа MCP. Сценарий использовал временную
копию базы. Пробный launcher записывал событие непосредственно перед
вызовом `Initialize`.

## Результаты

- **Оба ожидания, `open=225` с.** После 120,412 с ожидания `copy_path`
  launcher получил 104,588 с на открытие. Через 104,593 с ожидания
  стенда MCP вернул `blocked`, код 2, `open_timeout` и
  `timeout_phase=open`. Клиент получил сообщения об ожидании пути,
  подготовке копии и ожидании стенда в этом порядке. Мьютекс не захвачен,
  CDB, 1С и OLE-клиент не запущены, вызовов `Initialize` нет.
- **Только `copy_path`, `open=225` с.** Ожидание заняло 121,980 с,
  мьютекс захвачен за 0,001 с. Прогон завершился с кодом 0,
  одним вызовом `Initialize` и результатом 42.
- **Только стенд, `open=225` с.** Мьютекс захвачен после 120,143 с
  ожидания. Прогон завершился с кодом 0, одним вызовом `Initialize`
  и результатом 42.
- **Оба ожидания, `open=450` с.** Ожидание `copy_path` заняло 120,145 с,
  ожидание стенда — 120,119 с. После захвата мьютекса MCP сообщил
  о запуске 1С. Прогон завершился с кодом 0, одним вызовом
  `Initialize` и результатом 42.

Временная копия, замок и файл защиты удалены. Опись исходной базы,
список баз, COM-регистрации и список процессов 1С совпали со снимками
до прогона. Прошли 34 автоматических теста MCP и дедлайнов.

Сводка — `.artifacts/stage69-native-real/verified.json`. Локальная проба
запускается командой `python -B .local/s69-verify.py <новый-суффикс>`.
