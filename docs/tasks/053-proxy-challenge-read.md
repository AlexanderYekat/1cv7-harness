# Задача 053. Чтение маркера подтверждения прокси

Задача принята владельцем 9 ноября 2026 года в указанном охвате.
Основание приёмки — поручение «Принимай задачу 053 и коммить».

В задаче 052 монитор получил `PermissionError` при чтении уже видимого
`proxy-challenge-complete`. Сеанс остановился до Initialize. Цель задачи
053 — восстановить чтение после краткой блокировки и сохранить проверки,
которые предшествуют выдаче `initialize-permit`.

## Воспроизведение

В нативной пробе на исходном коммите `15a1cba` проверочный launcher
удержал эксклюзивный дескриптор Windows на `proxy-challenge-complete`
в момент фактического чтения. Получен `PermissionError` с `errno=13`.
В прогоне `7ac96bac-19b6-4440-b85e-3a0c907f7f47` зафиксированы один
Challenge, одна попытка чтения, ноль публикаций разрешения и ноль Initialize.

## Изменение

Монитор использует читатель маркеров из 051. Он ограниченно повторяет
чтение того же файла при ошибке доступа и записывает операцию
`proxy-challenge-read`, путь, код ошибки и номер попытки. Перед
чтением и после проверки рабочего стола проверяются отмена и сроки сеанса.

После успешного чтения монитор сверяет точный ID запуска и подтверждает
идентичность прокси и рабочего стола, затем публикует разрешение.
Чужой ID даёт отдельный отказ. Проверки используют наблюдение CDB и
существующую проверку владельца процесса. Повторы ограничены чтением файла.

## Нативная проверка

На свежей копии в прогоне `85482f11-dbb9-4fa0-9bc9-64a44e66a15b`
первая попытка получила ошибку 13, вторая прочитала точный ID запуска.
Подтверждены один Challenge, одна публикация `initialize-permit` и
один Initialize. Дальше штатный сценарий 052 один раз выбрал товар
и записал фактуру, а независимая проверка подтвердила сохранённые данные.

Постоянная блокировка в прогоне `af2c5d74-a88c-430e-9a94-be8b16c21c24`
дала отказ после 25 попыток примерно за секунду. Диагностика содержит
`proxy-challenge-read`, полный путь и ошибку 13. Чужой ID в прогоне
`67ea4d72-3bde-449c-a640-2291ef9f939d` отклонён с первого чтения.
В обоих случаях отмечен один Challenge, а публикаций разрешения и вызовов
Initialize было ноль.

Сводная сверка `.artifacts/stage53-native-verified.json` подтвердила
счётчики и сохранность источника, списка баз и чужих сеансов во всех
четырёх прогонах. Копии удалены, блокировки освобождены. Прошли 148
тестов платформы. Пять файловых проб 051 также прошли после повторного
запуска отдельно от нативных прогонов. Первая попытка превысила срок
ожидания процесса cscript.

Для пробы использованы локальный launcher `.local/s53-native-launcher.py`
и профиль `.local/s53-stand.toml`. Режимы задаются
`HARNESS77_PROBE53_MODE`. Изменения файлов в пробе ограничены каталогом
свидетельств текущего запуска.
