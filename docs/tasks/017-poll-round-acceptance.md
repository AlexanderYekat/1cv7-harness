# Приёмка задачи 017: решения по вопросам 015

Дата: 21 октября 2026 года. Задание — [017-poll-round.md](017-poll-round.md). Исходный HEAD:
`fea324a`. Владелец поручил решить оба вопроса задачи 015 по усмотрению исполнителя.

## Решения

- **`run` после выхода клиента MCP не продолжается** — поведение прежнее, обоснование
  записано в задании и в контракте MCP ([contracts.md](../contracts.md)): отмена тоже
  останавливает 1С принудительно; `run` без клиента незаметно держал бы стенд до срока
  профиля; оставшуюся регистрацию COM снимает следующий запуск (015). Формулировка
  контракта «следующий запуск отказывает до удаления регистрации», устаревшая после 015,
  исправлена.
- **Круг опроса launcher** получил замер шагов; источник 16-секундных кругов 015 синтетической
  нагрузкой не воспроизвёлся, поведение launcher не менялось.

- `research/platform77/session77.py`: `poll_rounds.step_max_seconds` (наибольшее время шагов

  и `poll_rounds.slowest` (те же шаги самого долгого круга), по `time.perf_counter`.

## Границы

- Почему в 015 круг доходил до 16 с, не установлено: синтетическая нагрузка процессора
  на равном приоритете и записи на диск круг не растягивает. Нагрузку памяти (подкачку)
  исполнитель не воспроизводил — она замедлила бы и работу владельца. При повторе
  внешней нагрузки `poll_rounds.slowest` в отчёте `run` назовёт медлящий шаг.
- Выход клиента MCP во время `run` по-прежнему останавливает свою 1С принудительно.
