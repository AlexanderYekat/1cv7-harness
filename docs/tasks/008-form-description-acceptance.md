# Приёмка задачи 008: описание формы ERT и первая кнопка

Дата: 18 октября 2026 года. Статус: **принято.** Задание — [008-form-description.md](008-form-description.md).
Исходный HEAD: `2d6b9d6`.

## Что реализовано

- **Продукт.** `harness77 form-extract ФОРМА.ert --output form.json` — описание
  формы в JSON (`harness77-form`, версия 1): заголовок, размер и слои формы;
  у элемента — ID, класс, подпись, x, y, ширина, высота, формула, идентификатор,
  слой. `harness77 build … --form form.json` собирает модуль и диалог за один раз;
  `[build] form` в профиле проекта; `lint --dialog` принимает описание. Контракт —
  [contracts.md](../contracts.md#описание-формы-задача-008).
- **Без потерь.** Диалог восстанавливается из дерева по одному правилу: CRLF перед
  каждым вложенным списком, два пробела после корня. Поля и разделы вне описания
  берутся из шаблона. Неканоническая разметка, неизвестная структура, другой
  шаблон (хеш диалога) — отказ.
- **Изменения:** заголовок и размер формы; у существующих элементов — подпись,
  положение, размер, идентификатор, слой, формула кнопки; новая кнопка в конце
  списка. Проверяется только заданное описанием. Отказ: удаление, перестановка,
  смена ID/класса, слои, другие классы новых элементов, формула не `Имя(…)` или
  без процедуры модуля и глобальной функции, кнопка вне клиентской области
  `[4, W − 3] × [15, H − 3]`, ID новой кнопки не следующий по порядку, недопустимый
  или повторный идентификатор, символы вне Windows-1251, смена вида заголовка длины.
- **Нативная проба** (`research/forms`): адаптер формы к launcher этапа 4 —
  видимое открытие, окна своего процесса на своём desktop, геометрия и DPI,
  `BM_CLICK` с перепроверкой идентичности процесса, ожидание клиента между
  `open` и `result`. В launcher добавлены точки расширения адаптера `client()`
  и `watch()`; по умолчанию поведение прежнее.

## Границы

- Проверены один шаблон (FIO.ERT), одна новая кнопка и вызов процедуры модуля
  `BM_CLICK`. Изменение свойств существующих элементов проверено только
  переносимо.
- Клиентская область и масштаб измерены на одном стенде: Windows 11, 96 DPI,
  шрифт формы MS Sans Serif 8. Для других шрифтов и DPI правило не проверялось.
- `BM_CLICK` — сообщение окну, а не нажатие мышью; нажатие пользователем
  проверено один раз вручную (F2m).
- Видимость и внешний вид автоматически не проверяются, пока главное окно скрыто:
  видимость подтверждена только глазами владельца в F2m. Это вход следующей
  задачи визуальных тестов.
