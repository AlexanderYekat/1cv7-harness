Релиз объединяет принятые задачи [108](108-check-combo-acceptance.md)
и [109](109-startup-publication-acceptance.md). Версия опубликована 18 ноября
2026 года. В тот же день владелец принял выпуск и проверку скачанного wheel.
[Релиз v0.15.0](https://github.com/AlexanderYekat/1cv7-harness/releases/tag/v0.15.0).

Аннотированный тег указывает на `b381faf7c5c5e980a9787880f64627b9a8b3c664`.
CI этого коммита прошёл на Windows с Python 3.11, 3.13 и 3.15 и на Linux
с Python 3.13. GitHub разрешил прямой push в master до появления обязательной
проверки `ci`. Публикация состоялась после успешного CI.
[Проверки GitHub](https://github.com/AlexanderYekat/1cv7-harness/actions/runs/44239054380).

## Сборка и скачивание

Сборка выполнена из `git archive`. Wheel собран из sdist. В изолированном
окружении выполнены 640 пакетных тестов, из них 5 пропущены. Все 73 файла
пакета сверены с принятой сборкой 109. В 29 файлах отличались переводы строк.
Соответствующие хэши в манифесте пересчитаны и проверены для каждой сборки.
[Отчёт сборки](../../.artifacts/s110-release/package/summary.json),
[сверка содержимого](../../.artifacts/s110-release/build-identity.json).

Из GitHub скачаны все три опубликованных файла. Размеры и SHA-256 совпали
с данными GitHub, а байты — с локальной сборкой и списком контрольных сумм.

- Wheel, 426014 байт, SHA-256 `1501ba0b1f7b010da4c5a259f9188e576ceeb49d16d0b8803d560d38429026d0`. [Скачать wheel](https://github.com/AlexanderYekat/1cv7-harness/releases/download/v0.15.0/harness77-0.15.0-py3-none-any.whl).
- Sdist, 1164085 байт, SHA-256 `f29eee18f55155020ee6ecfad795ac1cb7821c313575dbf2d2d5803a294d9433`. [Скачать sdist](https://github.com/AlexanderYekat/1cv7-harness/releases/download/v0.15.0/harness77-0.15.0.tar.gz).
- Список контрольных сумм, 192 байта, SHA-256 `7f2e2cc87ea73029aa2aad0c24173d09fc5c5dc65e1f719b54c769bb4f8d0955`. [Скачать SHA256SUMS.txt](https://github.com/AlexanderYekat/1cv7-harness/releases/download/v0.15.0/SHA256SUMS.txt).

Скачанный wheel установлен в новое окружение без обращения к индексам и без
зависимостей. Для нативной серии использован этот Python с исключёнными
`PYTHONPATH` и `PYTHONHOME`. 73 установленных файла побайтно совпали с wheel,
33 файла нативного runtime — с хэшами исходников в архиве коммита.
[Получение файлов](../../.artifacts/s110-release/publication-verified.json),

## Нативный стенд Windows / 1С 7.70.027 / DBF

`check_combo` дал последовательность `passed → failed → passed` через каждый
из `run`, CLI suite и MCP. Переименование невыбранного пункта обнаружено на
`/items/3`, при этом текущий выбор сохранился. При восстановлении исходного
модуля те же ожидания снова прошли. В девяти запусках сверены 21 снимок списка,
хэши снимков и входов, сравнения и диагностика. Содержимое снимков и результаты
сравнения совпали с принятой серией 108. Оба suite продолжились после `failed`.
[Серия check_combo](../../.artifacts/s110-release/native-108/verified.json).

Для проверки запуска диагностический launcher удерживал настоящий Windows reader
без `FILE_SHARE_DELETE`. Оба контроля на принятом wheel задачи 108 воспроизвели
WinError 5. В исправленной версии тот же конфликт выявлялся предварительной
проверкой доступа как WinError 32. В каждом из трёх транспортов восстановились
оба запуска с временной блокировкой. Первую блокировку создали до запуска
отладчика, вторую — после подтверждения владения сервером. После снятия
блокировки прошли все восемь шагов формы. Файлы установленного пакета не менялись.

Оба suite завершили все семь сценариев с четырьмя `passed` и тремя ожидаемыми
`blocked`. После постоянного запрета и короткого тайм-аута последний обычный
сценарий прошёл. MCP ответил на `ping` во время и после каждой серии. Сверены
JSON и JUnit. [Серия startup.json](../../.artifacts/s110-release/native-109/verified.json).

Шесть временных блокировок восстановились за 214–243 мс. Шесть постоянных
прекратили повторы примерно за секунду, сохранив SHA-256 прежнего `startup.json`.
Проверка отмены выставила `cancelled=true`, следующий обычный `run` прошёл.
Копия базы, lock и временные файлы публикации удалены. Листинг исходной базы,
хэши MD/DD/DLL, реестр и чужие процессы совпали до и после проверки.

Все 32 запуска скачанного wheel дали ожидаемые исходы. Из них 19 `passed`,
3 ожидаемых `failed` и 10 ожидаемых `blocked`. Два отрицательных контроля
выполнены отдельно на предыдущем wheel. Для всех 32 запусков проверены
путь установленного Python и хэш манифеста нативного runtime.
[Независимая сверка 109](../../.artifacts/s110-release/native-109/independent.json),
[итоговая сверка](../../.artifacts/s110-release/final-qualification.json).
