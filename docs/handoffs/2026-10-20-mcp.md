## Воспроизведение

```powershell
python -B -m unittest discover -s tests
.local/mcp-client/venv/Scripts/python -B research/mcp/verify_mcp77.py conformance --output .artifacts/mcp/c1-NEW
python -B research/mcp/claude_probe77.py lint --output .artifacts/mcp/claude-NEW
python -B research/mcp/claude_probe77.py shutdown --output .artifacts/mcp/claude-NEW
.local/mcp-client/venv/Scripts/python -B research/mcp/verify_mcp77.py run --name N1 --output .artifacts/mcp/native-NEW `
  --project .local/stage14-native/project-control.toml --stand .local/stage14-native/stand.toml --run-id <UUID>
.local/mcp-client/venv/Scripts/python -B research/mcp/verify_mcp77.py run --name N2 --output .artifacts/mcp/native-NEW `
  --project .local/stage14-native/project-long.toml --stand .local/stage14-native/stand.toml --run-id <UUID> --cancel-after-s 45
.local/mcp-client/venv/Scripts/python -B research/mcp/verify_mcp77.py close --name N3 --output .artifacts/mcp/native-NEW `
  --project .local/stage14-native/project-long.toml --stand .local/stage14-native/stand.toml --run-id <UUID> `
  --after-marker native/ert-execute-started --close-after-s 10
```

`run_id` нативного стенда — только UUID. После N2/N3 (принудительная остановка своей
1С) на базе остаётся `1Cv7.LCK`: следующий сеанс переиндексирует; профиль
`project-control-reindex.toml` даёт на это запас.

## Открыто

- **Выход из Claude Code во время `run`.** Claude Code снимает сервер и всех его
  потомков через 1–2 с после закрытия stdin (C3): своя 1С остановится принудительно,
  временная регистрация COM launcher (`HKCU\Software\Classes\Harness77Diagnostic.*`)
  по устройству launcher останется, следующий запуск launcher откажет до её удаления.
  Варианты — в задании (раздел «Исходы»); решает владелец.
- Сервер зарегистрирован в Claude Code владельца (область `local` проекта
  `C:\MyProjects\harness77`). В Windows PowerShell — `claude.cmd mcp add …`: PowerShell
  не передаёт `--` в `claude.ps1`. Проверка C4/C5 выполнена: Esc отменяет `run` с очисткой.
- **Launcher этапа 4 под нагрузкой** (не MCP): 20 с на запуск cdb своей 1С иногда мало
  (отказ до 1С); событие начала остановки, прочитанное только в начале круга опроса,
  пропускается при остановке за 0,4 с — `blocked` «shutdown deadline was not armed»
  после штатного выхода (N1c). Возможная задача — вместе с удалением своей оставшейся
  регистрации COM.
- Не входят: CI, ревизия `2026-07-28` протокола на стороне сервера, ресурсы и
  подсказки MCP, транспорт HTTP.
