## Что появилось

- `md-extract`: рядом с модулем каждой формы — описание её диалога `<модуль>.json` (схема
  `harness77-form` 3), индекс `modules.json` версии 2 (`forms`), `forms_not_described`.
- `md-build`: файл `.json` пересобирает диалог формы конфигурации; `form77.FormContext` — экспорт
  глобального модуля, поля реквизитов объекта (тип реквизита), отказы по табличной части, встроенным
  реквизитам и смене привязки; табличная часть — препятствие, её место в обходе
  (`table_part_position`) сохраняется; отчёт `changed_forms`, `unchanged_forms`.
- `metadata77.Attribute`: `length`, `precision`, `number`, `part`.
- `run`: модуль изменённой формы — изменённый модуль для статики и ошибок компиляции;
  `Обработка.<Имя>.Форма.Модуль` → `Обработка/<Имя>/Форма.1s`; `visual approve` записывает
  `configuration_sha256`.
- Launcher форм: `form_object`, `browser` в ожидаемом описании, ID окон с табличной частью, поля без
  рамки при подборе масштаба, ввод байтом Windows-1251 в ANSI-окно, надпись с формулой не сверяется
  с подписью; launcher этапа 4 — `select_base`.
- `research/forms/probe_md_forms77.py`, `scripts/verify_md_forms77.py`; тесты `test_md77_forms`.
- `lint` 0.6.0 (решение владельца после представления): L7711 — ошибка при известном глобальном модуле
  конфигурации; на базе стенда это 2 ошибки в форме `ВыборИзКлассификатораАдресов` — 1С подтвердила.
  `run` берёт глобальный модуль базы из `[build] metadata` или базы стенда (`static.global_module`).
