# Исследование 76.АВ

Скрипты извлекают из снимка конфигурации участки, связанные с 76.АВ и НДС с предоплаты. Это материалы конкретного исследования, а не универсальные компоненты harness.

- `inspect_76av.py` читает `.local/configurations/reference/1Cv7.MD`, используя `CompoundFile` из существующего devtools, и записывает текст метаданных и выбранные модули в `.local/research/76av`.
- `read_76av_context.py` читает эти выгрузки и печатает заранее выбранные фрагменты. Он рассчитан на конфигурацию данного исследования.
- `.local/research/76av/lint77-*.json` — исторические отчёты. Старые абсолютные пути внутри них описывают первоначальные запуски и не являются текущими настройками.

Из корня рабочей области:

```powershell
# Чтение уже сохранённых фрагментов; файлы не изменяются
python -B .\research\76av\read_76av_context.py

# Повторное извлечение; перезаписывает производные metadata.txt и modules/*.txt
python -B .\research\76av\inspect_76av.py
```

Пути вычисляются относительно файла скрипта, поэтому работа не зависит от текущего каталога оболочки. Платформа 1С не запускается, база не открывается и не изменяется. Для повторного извлечения нужен сохранённый локальный снимок конфигурации.

В ходе переноса исправлены только пути; исходные версии скриптов и выгрузок сохранены в `.local/maintenance/followup-layout-2026-10-10/before.zip`.
